## Public endpoint contract

- Normalize CRLF and CR to LF before deriving offsets.
- Source-page comments are excluded from selector candidates but remain in the
  raw coordinate space.
- A line record exposes `start`, `content_end`, and `full_end`.
- Semantic start is the start selector's line start; semantic end is the start
  of the end selector. `page_start` is the first nonblank non-comment content
  line. `page_end` is the full end of the last nonblank content line.
- Suppression start is `start_line.start`; suppression end is
  `end_line.full_end`, including the terminal LF when present.
- Hash the exact UTF-8 half-open raw slice. Never strip, rstrip, or reconstruct
  it from split lines.
- The same resolved suppression slice is used for validation, deletion,
  provenance, and conservation.
