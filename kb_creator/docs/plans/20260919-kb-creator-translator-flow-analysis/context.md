# Текущий контекст

Goal id: `20260919-kb-creator-translator-flow-analysis`. State: `completed`.

## Предложение пользователя для анализа

Идеальный вход — английский PDF. Минимальный обязательный выход продукта
«переводчик» — русский DOCX и папка ассетов. HTML и PDF не обязательны для
первого результата. После пользовательской проверки и правки DOCX можно
отдельно собрать окончательный русский PDF. ArtView не должен быть обязательным
шагом; он включается по запросу или когда конкретный визуальный вопрос нельзя
решить автоматически. Важные сильные стороны существующей работы — MinerU с
метаданными и документальный перевод с литературной вычиткой.

Предложенная последовательность: `PDF_EN -> MinerU -> reconstruction.md +
metadata.json -> очищенный и дополненный MASTER_EN -> переведённый MASTER_RU
-> оформленный DOCX + assets -> пользовательские правки DOCX -> PDF_RU`.
Очистка включает мусор, якоря иллюстраций и полезные данные из метаданных;
оформление — иллюстрации, таблицы, статблоки и полировку. Точные условия
автоматического выбора арта и форматирования ещё предстоит определить.

Уточнение пользователя: точка издательской полировки переносится в DOCX именно
для уменьшения кастомизаций `MASTER_RU`. Путь `PDF_EN -> reconstruction ->
MASTER_EN -> MASTER_RU` должен быть максимально простым и повторяемым.
`MASTER_RU` сохраняет текст и необходимую структуру (включая различие таблицы,
списка и статблока), но не должен служить местом для настройки макета книги.

## Текущая граница

Это рабочая формулировка нового целевого режима, а не отмена существующей
публикационной политики для уже начатых/принятых запусков. Нужен исторический
учёт более ранних книг, а не оценка только по Dissociation и Number 7 Dream.

## Найденные доказательства

Имеются не менее восьми отдельных произведений в истории `kb_creator` и
`translator`: Innsmouth, Viral, Dissociation, Number 7 Dream, Wormsign,
Desertflower, Bless the Beast and Children, Mothers Love. Их охват и ограничения
принятия разделены в `handoffs/A2-book-inventory.md`; поправка на одну
относительную ссылку — в `handoffs/A2-book-inventory-links-correction.md`.
Современную общую публикационную цепочку доказывают Dissociation и Dream;
Viral и Innsmouth используют более ранние/сценарные контуры. У прежнего
`translator` есть выборочные ветки арта/PDF, но нет доказанного DOCX-по-умолчанию.

Предложение пользователя оформлено в
`../../translator-docx-first-flow-proposal-20260919.md`. Действующий код
по-прежнему требует принятых ArtView и HTML перед DOCX и отдельного
представленного перевода. Временный HTML как внутренний вход текущего DOCX
builder — возможный путь минимального режима; прямой builder из MASTER_RU
не выбран. Принятые контракты и артефакты не менялись.

составить отдельный implementation goal и провести сравнительную сборку DOCX
из принятых мастеров на разных типах источника.
