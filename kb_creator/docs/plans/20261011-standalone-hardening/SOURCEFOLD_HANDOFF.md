## 1. Что такое Sourcefold (коротко)

Новый проект на смену kb_creator (D10). Цель (D12): из PDF настольных RPG
(сейчас Call of Cthulhu 7e) получать **документально точный структурированный
двуязычный материал** (EN-источник + RU-перевод): текст, таблицы, раздатки,
статблоки персонажей, плюс арты и метаинформацию. Подключается глобальный
словарь терминов.

**DOCX и человеко-читаемый материал — отдельный проект.** Конечная цель —
единая база (сценарии, правила, таблицы, персонажи), доступная как
веб-приложение и как модуль Foundry.

Источники системы:

- kb_creator (архив): ядро конвейера — реконструкция PDF тремя видами
  MinerU, аудит покрытия, языковой шаг с проверкой чисел и терминов,
  примитивы идентичности;
- git_coc (`https://github.com/Hramgithub/git_coc`, локально
  `C:\_Hobby\_work\git_coc`): веб-помощник Хранителя по русской книге правил;
- NRI `FoundryVTT/modules/nri-coc-library`: целевой формат экспорта
  CoC7 8.13;
- `https://github.com/Hramgithub/CoC` (`terminology/`): общий словарь;
- `https://github.com/Hramgithub/tools`: будущий источник проверенных
  инструментов (пока пуст).

## 5. Как работать (договорённости с владельцем)

- **Коммит и push в `main` — по умолчанию, без отдельного вопроса.**
  Force push, переписывание истории и `lfs migrate` — только с явного
  подтверждения.
- Обсуждение решений — **по одному вопросу**, с рекомендуемым вариантом;
  ответ сразу записывается в `decisions.md` (или в аналог в новом репо) и
  коммитится.
- Общение на русском; документы на русском, с понятными предложениями без
  сокращений-кодов.
- Окружение: Windows, PowerShell. `git` — cmd-обёртка: сообщение коммита
  передавать файлом (`git commit -F <file>`), не через stdin; в аргументах
  `git grep` не использовать `|` внутри регулярного выражения.
- В kb_creator `.gitignore` по схеме default-deny: для поиска по
  отслеживаемым файлам надёжнее `git grep`.
- Не изменять NRI без явного запроса (это отдельный репозиторий владельца);
  читать можно.
- Исходные PDF лежат у владельца на Яндекс.Диске (`НРИ/1_Зов Ктулху`);
  часть файлов только в облаке и отдаётся медленно.
