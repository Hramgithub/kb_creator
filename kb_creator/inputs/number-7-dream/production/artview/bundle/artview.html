ArtView v4

Кликните по нужному варианту изображения: выбранная карточка будет обведена зелёным, а строка получит статус «Выбор сделан». При необходимости настройте параметры представления. Ничего не применяется автоматически.

Импорт прошлого конфига ArtView

Точный JSON текущего кандидата восстанавливает выбор и отметки проверки. JSON от прежнего кандидата переносит только совместимые решения; отметки проверки сбрасываются и требуют нового клика по каждому выбранному варианту.

Выберите экспортированный ArtView JSON.
